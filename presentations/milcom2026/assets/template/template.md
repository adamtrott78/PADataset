# Official MILCOM 2026 presentation template

These files were supplied by MILCOM for the 2026 conference and are authoritative branding/layout references for the DQNGuard presentation.

Files:

- milcom26-ppt-template_v1_25feb26_jb.pdf
- milcom26-ppt-template_v1_25feb26_jb.pptx

The PDF contains four 16:9 slides:

1. blank title background;
2. blank content background;
3. populated welcome/title example;
4. populated content example.

The SVG production workflow uses PDF page 1 for Slide 1 and PDF page 2 for Slides 2–12 so the MILCOM and IEEE ComSoc marks, Washington DC imagery, header treatment, and footer are preserved exactly.

The PPTX should remain unchanged and be used as the conference template source when the final PowerPoint package is assembled.

See ../../MILCOM_TEMPLATE_INTEGRATION.md for the production contract.
