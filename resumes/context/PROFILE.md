# Candidate professional profile

Status: **public-safe working summary; not yet populated**

This file will provide a concise current professional profile for resume planning.

It is intentionally not a traditional "master resume" and is not the final
authority when facts conflict.

## Authority

`EVIDENCE.md` owns candidate factual claims.

This file summarizes evidence for efficient cold-start use. If this file and the
evidence ledger disagree, stop and resolve the discrepancy rather than silently
choosing the more convenient wording.

## Privacy rule

Only public-safe professional information belongs here.

Do not place private contact details, private identifiers, sensitive application
information, medical/legal/clearance information, or other restricted personal
context in this tracked file.

## Planned profile categories

- current academic status;
- completed education;
- research experience;
- teaching experience;
- technical projects;
- publications and presentations;
- technical skills;
- awards and public-safe distinctions;
- prior employment that may be relevant to future applications.

Populate these categories only from reviewed evidence.
